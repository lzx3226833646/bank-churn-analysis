# 银行客户画像分析 —— 我的第一个金融数据项目

## 项目背景
本项目基于 Kaggle 公开数据集 "Bank Customer Churn"，对银行客户的基本画像进行初步探索，为后续流失预测和精准营销提供数据支撑。

## 数据来源
- 数据集名称：Customer-Churn-Records.csv
- 记录数：10,000 条
- 关键字段：年龄、性别、国家、信用评分、账户余额、使用产品数

## 核心业务洞察（基于 SQL 查询）
1. 年龄大于 40 岁的女性客户共 **1,704** 人，是中长期理财产品的重点潜在客群。
2. 各国客户平均信用评分相近：法国 **649.7**，德国 **651.5**，西班牙 **651.3**，表明信用风险在区域间无明显差异。
3. 账户余额超过 10 万且产品使用数不超过 2 个的客户共 **4,631** 人，属于“高价值但低活跃度”的沉睡客群，建议优先触达。
